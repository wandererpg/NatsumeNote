# NatsumeNote v_1.1（1.1.0）

日期：2026-10-22。整理范围为上次 0.1.0 打包之后的开发更新。

## ReinaManager 与游玩历史

- 在设置中选择 ReinaManager 数据库，只读查询历史总时长、游玩日期、时段和会话；不需要开放端口，不写入来源数据库。
- 支持已核对的 ReinaManager NextMoe 数据库结构，并提示常见数据库位置与读取失败原因。
- 浏览全部来源作品，先预览历史时长，再确认关联；来源累计与已保存会话合计分别展示，不相加，也不将缺失值显示成零。
- 将已选游玩记录插入对应作品的手账历史卡片，保留来源与分钟精度信息。

## 批量导入与自动匹配

- 一次预览并导入全部作品，按已有明确关联、唯一资料编号或完整标题匹配本地作品；没有匹配的可新建作品与文件夹。
- 支持逐项手动关联、新建或跳过，处理目录重名和无效字符，避免覆盖已有文件夹；重复导入沿用已有关联。
- 修复“确认导入”因待确认项目而一直灰色的问题：点击后说明原因，并跳转、聚焦到需要处理的项目，包括其他分页。
- 修复导入后仍重复按文件夹名搜索资料的问题：优先使用已确认的 VNDB/Bangumi 编号，恢复旧的待选、未匹配或无编号失败缓存。
- 已有匹配资料与手动选择优先保留；来源编号缺失、冲突或关联待重新确认时仍需核对候选。
- 修复已打开详情页无法感知新关联的问题。资料刷新保留已有简介，网络失败显示提示，可在作品编辑器中重试。

## 整理、同步与音乐体验

- 标签显示来源，支持展开全部及多选 AND 筛选；手账整理标签独立保留。
- 增加音乐库手动双向同步：导出同步文件夹，另一端选择 `manifest.json`，预览后合并歌曲、收藏、播放列表及作品资料。
- 纳入页面切换与按钮动效、加载提示、外观设置保存修复，以及切换音乐目录后的识别改进。
- 纳入播放键播放/暂停切换、删除曲目后保留页面位置和资料候选确认流程改进。
- 同步 AFA/BGI 等游戏资源格式支持，保留原有 NWA 转换和曲目文件定位功能。
- 调整“全部作品”“导入游戏数据”等界面文案。

## 安装与数据

Windows x64 安装程序：`NatsumeNote-1.1.0-x64.exe`。本地构建输出到 `release-v_1.1/`，保留旧版构建。安装前建议备份 `%APPDATA%\NatsumeNote\galmusic.db` 与音乐库；升级使用原来的应用标识和数据目录，数据库迁移至 schema 9。

联网资料为可选增强；来源没有提供的历史数据无法凭空补全。手动同步不包含作品手账页面和手账素材，需另行备份。

本次准备本地安装包、便携包和校验文件，并推送源码与文档更新。第三方材料沿用现有草稿与复核状态；公开分发前仍须处理 [第三方声明](../../THIRD-PARTY-NOTICES.draft.md)列明的遗留事项，本文不宣称已完成许可清理或已发布 GitHub Release。
