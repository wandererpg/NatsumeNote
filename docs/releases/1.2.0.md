# NatsumeNote v_1.2（1.2.0）

日期：2026-10-27。本地 Windows x64 构建，包含 v_1.1 之后的手账界面与交互更新。

## 更新内容

- 重整页面导航、插入工具栏、可收起的属性面板和纸面排版，沿用七套主题。
- 复用 Anime.js 的短过渡，支持系统“减少动态效果”设置。
- 明确卡片移动与缩放手柄，支持方向键微调、Escape 取消拖动、页签键盘导航和记忆模式焦点管理。
- 小窗口默认保留可读编辑比例，可手动缩放或适应窗口查看整页。
- 保存顺序处理后续输入，离开页面时补存；离开时保存失败的草稿在应用运行期间保留，再次打开可恢复并重试。
- 防止旧作品的异步创建、素材导入和删除响应覆盖新作品；创建期间的后续输入先保存再切页。

## 打开本地版本

- 直接运行：`release-v_1.2/win-unpacked/NatsumeNote.exe`。请保留同目录的 DLL、`locales/` 和 `resources/`。
- 安装使用：`release-v_1.2/NatsumeNote-1.2.0-x64.exe`。
- 分发压缩包和校验值由 `node scripts/verify-release.mjs release-v_1.2` 生成。

沿用 `com.natsumenote.app`、`NatsumeNote` 应用名称和现有用户数据目录，不改数据库结构。旧版构建保留在原目录。打包和验证使用合成数据，不启动或修改用户的实际音乐库；本次不上传或发布 GitHub Release。
