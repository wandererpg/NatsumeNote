# NatsumeNote v_1.3（1.3.0）原地更新

本次以已有的 `release-v_1.2-update/win-unpacked/` 为更新目标，直接替换该应用所需的界面资源。没有另建示例应用、版本目录、Windows 安装包或便携压缩包。

## 查看方式

直接运行已有应用：

```text
D:\Codex\NatsumeNote\release-v_1.2-update\win-unpacked\NatsumeNote.exe
```

标题栏显示 `v_1.3`。作品资料、游玩记录、音乐与手账继续使用原应用的数据，不需要导入到另一套示例库。

源码开发运行 `npm run dev`，由 Electron + Vite 启动这套桌面界面。

## 本次界面改进

- 简介与主创团队在适配后的可视区域内滚动，完整内容仍可访问。
- 标签放在作品右栏，简介中的来源尾注和加载失败长句不再显示。
- 游玩记录与作品资料同级，来源总计及每日时长折线图放在页面上方，作品关联和数据来源放在下方。
- 移除日期范围、会话累计、旧会话列表及来源说明小字。
- 每日时长按本机时区的会话开始日期汇总来源保存的分钟；同日合并、缺日归零、跨午夜记录归入开始日期。
- 历史会话自动读取全部分页，支持悬停与键盘查看图表具体日期和时长。
- 保留手账界面、编辑和动画的已有改进。
- 作品资料首块的简介可视区域随右侧信息栏高度自适应延长，编辑按钮和来源链接靠底对齐；封面恢复原有尺寸、比例和显示方式。
- 人物资料与主创团队的顶部、底部对齐，主创名单的可视高度跟随人物区域，超出部分内部滚动。只有单侧资料时占满可用宽度；窄屏上下排列时恢复有高度上限的名单。

应用名称、应用标识、用户数据目录与数据库结构保持原有约定。此次更新目标只有 `release-v_1.2-update/win-unpacked/`；其他安装包、压缩包及 `release-v_1.2/` 不随本次更新变化。
