# NatsumeNote v_1.3（1.3.0）开发版

本次更新提供 Vite 开发预览，未重新生成 Windows 安装包或便携版。

## 查看方式

在项目目录运行：

```powershell
npm run dev:web
```

打开 [http://127.0.0.1:5173/](http://127.0.0.1:5173/)，标题栏及浏览器标题显示 `v_1.3`。从游戏仓库进入示例作品，可以切换作品资料、游玩记录、音乐和手账。

浏览器开发预览使用独立示例库，手账与主题编辑保存在浏览器本地。它不会连接桌面版 SQLite、ReinaManager 数据库或用户音乐目录。已有 Electron 桥接时仍使用桌面服务，浏览器演示桥接仅在开发环境且没有桌面桥接时启用。

桌面应用的开发启动方式仍为 `npm run dev`。

## 本次界面改进

- 简介与主创团队提供有高度上限的内部滚动区域，完整内容仍可访问。
- 标签放在作品右栏，简介中的来源尾注和加载失败长句不再显示。
- 游玩记录与作品资料同级，来源总计及每日时长折线图放在页面上方，作品关联和数据来源放在下方。
- 移除日期范围、会话累计、旧会话列表及来源说明小字。
- 每日时长按本机时区的会话开始日期汇总来源保存的分钟；同日合并、缺日归零、跨午夜记录归入开始日期。
- 历史会话自动读取全部分页，支持悬停与键盘查看图表具体日期和时长。
- 保留手账界面、编辑和动画的已有改进。

应用名称、应用标识、用户数据目录与数据库结构保持原有约定。已有 v_1.2 构建仍保存在原目录；此次开发版不会更新这些可执行文件。
