# 作品资料布局整理

按用户反馈缩短作品资料页：简介与主创名单限制可视高度，内部滚动读取全部内容；标签移入右栏；游玩记录从资料页分离为同级栏目。沿用 ui-ux-pro-max 的内容层级、渐进展示和键盘可访问建议。

## 实现

- 简介的原文与译文放入同一可聚焦滚动区，语言工具栏保留在外；主创名单全量渲染，支持滚动与键盘焦点。
- 右栏使用浏览模式的标签组件，保留来源和筛选动作，不显示不适用于档案的 AND 筛选摘要；其他标签筛选保持原行为。
- 删除资料页冗长失败提示；只在展示时清理简介 BBCode 和独立尾行来源标记，不修改缓存、数据库或真实剧情内容。
- 新增“游玩记录”一级导航，复用既有 ReinaGamePanel 和异步边界，切换作品隔离数据。

## 验证

- 94 个测试文件、589 项测试全部通过，包含新导航、完整主创名单、右栏标签交互、来源清理和剧情保留回归。
- TypeScript、资源检查和生产构建通过。
- 合成数据 Electron 场景覆盖深色、浅色、960×640 窗口和双语；验证实际滚动与布局，未使用真实数据库。
- 独立复核已修复可能误删正文中 `[From …]` 的匹配边界，来源清理仅匹配独立尾行，不跨越首个链接结束标记。
- 调整版仍使用 1.2.0，单独打包到 `release-v_1.2-update/`，不覆盖原包或用户数据，不发布远程版本。
- 本地产物核对通过：打包代码与本次构建一致、SQLite 原生模块与 Reina 查询运行时正常、更新配置与安装包哈希一致、安装/便携 ZIP 完整性通过。
- 沿用本机已验证的分步打包方式，单独写入图标和版本，再从完整目录生成安装包；目录打包时补入相同发布配置的 `app-update.yml`，重新生成安装包后通过完整核对。
