## 限制与待实测

本轮没有检查安装版数据文件、运行中进程或用户个人记录。未发现已有 MCP server 不等于保证所有分支都不存在；本设计基于上述工作树。历史 game_sessions 表未保存计时模式或手工来源类型，不能可靠推断。仅查持久化数据不能取得内存中的当前会话。

## 标签交互依据

ui-ux-pro-max 定向查询 `badge chip label wraps filter selected keyboard`（ux）建议标签组换行，完整标签保持单行；超长标签提供可操作的完整内容入口；隐藏标签有明确的 +N 展开操作；异步筛选结果用单一状态区提示，避免每个标签独立播报。沿用 NatsumeNote 主题，不照搬 ReinaManager 的 MUI 或翻译资源。
